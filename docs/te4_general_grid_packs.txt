## Usage
Used by `dccb-tileset-gallery` for comprehensive terrain loading.
The gallery loads this list via: `/data-dccb/dccb/tileset/te4_general_grid_packs.lua`

## Loading Strategy
1. basic.lua is loaded first (provides base entities)
2. All other packs loaded with pcall for error handling
3. Only successful loads are counted and logged
4. Failed loads are reported with error messages
5. Summary shows: attempted / loaded / failed counts

## Fallback
If pack list file unavailable, falls back to minimal 9-pack list:
- water, forest, lava, mountain, jungle_hut, crystal, ice, sand, void
